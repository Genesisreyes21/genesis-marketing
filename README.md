# Génesis Reyes — Portfolio

A responsive, playful editorial portfolio: four academic marketing/creative-industry case studies, eight published articles, a Notion blog link, and a featured TikTok with profile access.

## Publish on GitHub Pages

1. Create a GitHub repository for your portfolio.
2. Upload ALL files from this folder, preserving the `assets` folder. `index.html` must be at the repository root.
3. In the repository, open Settings → Pages. Choose “Deploy from a branch”, select your main branch and `/ (root)`, and save.
4. GitHub will display your public website address after deployment. Share that address.

No installation, build command, API keys, or paid hosting required. The files also work on other static web hosts.

## Update your work

- Edit `content.js` to change project summaries or add articles. The first three articles are featured; the rest appear under “Keep reading”.
- Add PDFs and cover JPGs to `assets/`, then reference their relative paths in the project entry.
- Edit `index.html` to change your introduction, profile links, or featured TikTok. Replace the numeric video ID in the iframe URL with the ID from a full TikTok video link.
- Edit `style.css` to change colors, type, and spacing.
- Keep team credit and the academic-work labels when presenting group assignments. Budgets and strategies described here are proposals, not completed client engagements or measured outcomes.

## Content & external services

The four PDFs are copies of selected work from the owner's Downloads folder. Group collaborators remain credited. No CV, phone number, private documents, or research working files are included in this package.

Article links come from the owner's Published Articles collection. The three featured pages were opened and checked. The Notion home page was accessible during review, but its All Posts database showed “No results”; article links are independent of that database.

The TikTok short link resolved to @_genesisreyess/video/7683976121838325013, “Día conmigo como estudiante paraguaya en Abu Dhabi”. The embedded TikTok player was blocked in the local preview environment. The player loads only when the visitor clicks “Load featured video”. TikTok controls playback and availability; a direct video link and profile link are always shown. Videos may require consent or sign-in depending on viewer location and browser. The site does not download or rehost TikTok content.

Google Fonts provides DM Sans and Playfair Display with system font fallbacks. TikTok and fonts require an internet connection. Core portfolio navigation, case studies, and local PDFs work without those services.
